ESP32 / LVGL / Cloudflare Worker

1.47 inch US Stock Ticker

A compact desktop market screen built on the Waveshare ESP32-S3-LCD-1.47B. It tracks selected US stocks through a cloud proxy, keeps the last successful quote on screen, and supports Wi-Fi setup through a local configuration portal.

Firmware Repository Release v2.0.0

Project Role

A tiny hardware terminal for market glanceability.

This project turns a small ESP32-S3 display board into a practical desk companion: one screen, two buttons, RGB status feedback, and a stable cloud-backed quote pipeline.

The goal is not to replace a trading app. It is designed for quick awareness: current price, percentage move, selected symbol, update time, and a product-like setup flow.

Product Specifications

Hardware platform

Based on Waveshare ESP32-S3-LCD-1.47B Type B.

Board Waveshare ESP32-S3-LCD-1.47B
Processor Xtensa 32-bit LX7 dual-core, up to 240 MHz
Wireless 2.4 GHz Wi-Fi 802.11 b/g/n, Bluetooth 5 LE
Memory 512 KB SRAM, 384 KB ROM, 8 MB PSRAM, 16 MB Flash
Display 1.47 inch IPS LCD, 172 x 320 pixels, 262K colors
Display Driver ST7789, 3-wire SPI
Onboard Sensors QMI8658 6-axis IMU: 3-axis accelerometer + 3-axis gyroscope
Storage Micro SD / TF card slot
Controls & I/O BOOT button, RESET button, expanded GPIO, full-speed USB serial
Power & USB USB Type-C, battery charging management, 3.7 V lithium battery interface
Status Light RGB LED with transparent acrylic light guide

Current Feature Set

Firmware behavior

Market Display

Shows selected US stock symbols, latest quote, daily change, percentage move, page index, and update time.

Stable Refresh

Refresh runs in the background. The screen keeps the last successful quote instead of clearing into a loading state.

Setup Portal

If Wi-Fi cannot connect, the device starts a local hotspot and browser setup mode for Wi-Fi and symbol configuration.

Cloud Proxy

A Cloudflare Worker hides API details, reduces ESP32 HTTPS pressure, and returns compact JSON for the device.

Two Buttons

Physical buttons are used for page switching and setup entry, matching the constraints of the tiny hardware format.

RGB Feedback

The onboard RGB LED reflects price movement direction with a color language that matches the UI.

System Architecture

Small device, cloud-assisted data path.

The ESP32 does the local display, setup flow, button handling, and timed refresh. Market data is requested through a Cloudflare Worker endpoint, which keeps the firmware simpler and more stable.

01 ESP32-S3 device boots

Shows startup screen, scans saved Wi-Fi, then enters stock UI or setup mode.

02 Cloudflare Worker proxy

Receives compact quote requests and returns device-friendly JSON.

03 Market quote provider

Provides stock quote data through an API, isolated from the device firmware.

04 LCD + RGB output

Displays price and movement, while RGB lighting mirrors up/down state.
